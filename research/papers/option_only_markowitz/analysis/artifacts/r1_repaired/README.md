# R1 Repaired Development Artifacts

These files are generated by `make r1-repaired`. They are intentionally separate from
the legacy E1 ledgers.

- `r1_monthly_development_returns.csv`: one point-in-time monthly R1 decision and return.
- `r1_monthly_weights.csv`: realized whole-contract premium weights by month.
- `r1_survival_summary.csv/json`: survival-first development metrics and hard verdicts.
- `r1_paired_bootstrap_comparisons.csv`: paired circular-block log-growth and expected-
  shortfall comparisons against matched capped-naive options and stock Markowitz.
- `research_trial_registry.csv/json`: all reconstructable trials, explicitly reported as a
  lower bound because undocumented research iterations cannot be recovered.
- `prospective_freeze_manifest.json`: source hashes, environment, fixed risk policy,
  endpoints, data cutoff, and the 36-month prospective confirmation rule.

Every observation currently in this directory is retrospective development evidence.
None is an untouched or externally preregistered holdout.

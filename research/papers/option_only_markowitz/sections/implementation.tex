\section{Implementation}

The reusable implementation is
\path{src/portfolio/option_only_markowitz_model.py}.  The key public
objects are:
\begin{itemize}[leftmargin=2em]
  \item \texttt{OptionOnlySpec}: validates the option universe and
  required Greek columns.
  \item \texttt{FactorShockSpec}: stores underlying-return and
  implied-volatility-shock covariances.
  \item \texttt{OptionOnlyMarkowitzModel}: builds $B$, $\Omega$,
  $\Sigma_O$, the closed-form tangency direction, constrained
  maximum-Sharpe portfolios, equal-premium and equal-risk baselines, and
  risk-calibration diagnostics.
  \item \texttt{taylor\_option\_pnl}, \texttt{nearest\_psd}, and
  \texttt{shrink\_covariance}: testable numerical primitives.
\end{itemize}

The empirical runner is
\path{research/papers/option_only_markowitz/analysis/run_empirics.py}.
It writes:
\begin{itemize}[leftmargin=2em]
  \item generated LaTeX tables in \path{tables/};
  \item generated PDF figures in \path{figures/};
  \item machine-readable returns, weights, random-portfolio Sharpes,
  timing diagnostics, split adjustments, factor regressions, P\&L
  attribution, regime splits, leave-one-out diagnostics, claim-audit
  records, and \path{tables/empirical_summary.json}.
\end{itemize}

The contract is simple: every number quoted in the empirical section is
generated by the runner, and the paper compiles without network access.

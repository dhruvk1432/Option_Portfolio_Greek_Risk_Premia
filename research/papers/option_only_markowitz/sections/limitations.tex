\section{Limitations}

\paragraph{Local approximation.}
The Taylor expansion is local.  It is best for short horizons and fails
around jumps, discontinuous dividends, exercise boundary changes, and
large volatility-surface repricings.  The residual covariance term
absorbs part of this misspecification but does not eliminate it.

\paragraph{Rolling bucket returns.}
The empirical option assets are rolling buckets, not permanent listed
contracts.  This is necessary because listed contracts expire.  The
bucket return panel checks whether option-style exposures can be
allocated with Markowitz machinery; it is not a fill-level backtest. The
current local data support listed-expiry payoff using raw daily
underlying closes and split conversion, but they do not provide a
fill-level option liquidation, exercise, assignment, or margin model.

\paragraph{Expected returns.}
The conditional expected-return model is economically structured but still simple.  It
uses carry, historical means, volatility and skew proxies, relative value, and state
variables with strong shrinkage toward zero.  It is a research-grade forecast ledger, not
a production alpha model.  The paper's test-window Sharpes should therefore be read as
evidence about the measurement stack and payoff geometry, not as evidence of a stable
deployable premium.

\paragraph{VIX settlement.}
The VIX option layer uses raw contract-level chains and VX-forward Black--76 Greeks, but
VIX option expiry P\&L is exact only when the generated settlement audit shows complete
VRO/SOQ final settlement coverage.  If exact rows are absent or incomplete, VIX option
expiry returns are labeled as VIX-close settlement proxies.  That proxy mode is acceptable
for theory validation and hedge-sleeve diagnostics, but it is not exact listed VIX option
settlement P\&L.

\paragraph{Research cost layer.}
Transaction costs, slippage, margin financing, and assignment frictions are modeled only
through the conservative research cost layer. The paper does not contain live broker fills,
broker margin preview, or order-routing evidence. Option
premium is included in P\&L; broker margin and stress collateral are not.
Those frictions belong in a separate implementation-cost layer, not in
the definition of the option-only Markowitz analogue.

\paragraph{American single-name options.}
The data layer uses American-model/de-Americanized Greek proxies. This is
necessary because listed U.S. single-name equity options are American
style, while the local Taylor map uses European-equivalent sensitivities
as a standardized risk representation. Stale, wide, locked/crossed, or
parity-inconsistent quotes must be filtered before such Greeks are used
for portfolio construction.

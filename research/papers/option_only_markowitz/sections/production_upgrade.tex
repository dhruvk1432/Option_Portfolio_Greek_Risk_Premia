\section{Production Promotion Layer}

This release adds a production-promotion layer next to the research paper, rather than
relabeling the research backtest as production evidence.  The distinction matters.  The
paper's theorem and point-in-time empirical ledgers answer whether an option-only
Markowitz object can be defined, estimated, constrained, and audited.  A trading system
must additionally prove that the same decisions survive exact settlement, executable
quotes, fills, explicit fees, margin, assignment, borrow, capacity, broker reconciliation,
and live timestamp controls.

\paragraph{Code boundary.}
The production layer lives in \texttt{src/option\_portfolio\_production}.  It provides
broker-neutral schemas for timestamped OPRA/broker quotes, option contracts, NAV-to-contract
orders, fills, account state, positions, margin estimates, and hard pre-trade gates.  It
also provides exact VIX VRO/SOQ settlement ingestion, NBBO-based fill estimates, explicit
option fees, American option exercise and assignment utilities, conservative internal
margin/stress estimates, a broker-neutral adapter interface, an IBKR-paper-style in-memory
adapter for certification tests, and a separate production verifier.  These modules are
not used to inflate the paper's current performance tables; they are the path by which a
future production appendix must be generated.

\paragraph{Hard downgrades.}
The production verifier is intentionally stricter than the research verifier.  Headline
VIX-option production results must use \texttt{vro\_soq\_exact} settlement.  A VIX-close
proxy can remain in diagnostics, but it fails production verification.  Execution results
must come from order and fill ledgers; midpoint fills without a fill model fail.  Short
options must have margin rows, stress-loss estimates, assignment notional, and pre-trade
risk-gate status.  Broker positions and vendor quotes must reconcile.  Missing ledgers are
critical failures, not warnings.

\paragraph{Broker execution.}
The first executable target is IBKR paper trading behind a broker-neutral interface that
covers account state, positions, order preview, submit, cancel, replace, fills, margin
preview, and position reconciliation.  Live routing remains disabled by default.  Market
orders are rejected except for explicitly coded emergency risk reduction, and a kill switch
must block submissions immediately.

\paragraph{Acceptance standard.}
The current paper remains research/audit grade.  A future production appendix can be called
production grade only after the production verifier exits cleanly with exact VIX settlement,
post-cost/post-slippage fills, margin-constrained orders, assignment and borrow controls,
capacity limits, vendor timestamp reconciliation, and broker position reconciliation.  Until
then, any production claim is downgraded to a blocked implementation claim.
